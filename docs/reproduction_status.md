# 검증 및 재현 범위

## 보존 자료에서 확인한 사항

- 기존 네 분할의 파일 목록은 각각 350/75/75이며 저장된 파일명 목록 해시와 일치합니다.
- 학습 로그 16개는 공통 epochs 100, batch 4, imgsz 1280, patience 15, seed 0과 해당 증강 ON/OFF 설정에 대응합니다.
- 가중치 16개와 예측 폴더 32개는 원본 보존 묶음에 존재합니다. 공개 저장소에는 넣지 않았습니다.
- `research_core.py`의 기존 함수는 원문 AST와 대조합니다. 공개본의 실제 코드 검사 결과는 [verification.md](verification.md)에 기록합니다.

## 실행하지 않은 사항

실제 데이터로 학습·추론·완전일치 평가를 다시 실행하지 않았습니다. 분할 복원과 복제의 검사는 작은 가상 파일만 사용합니다. 코드 검사의 성공은 논문 성능 재현이나 새 GPU 환경의 동작 보장을 의미하지 않습니다.

평가 CLI는 한 분할의 결과를 저장합니다. 논문의 네 분할 평균±표준편차와 통합 CI를 자동으로 생성하는 전체 집계 명령을 제공한다고 주장하지 않습니다. 원문을 보존한 `load()`의 파일 열기 방식 때문에 단위 검사에서 `ResourceWarning`이 표시될 수 있습니다. 연구 함수 AST를 유지하기 위해 이 구현을 조용히 바꾸지 않았습니다.

## 연결이 부족한 재현 자료

1. 최종 논문의 표 2와 본문은 네 기반 모델·네 분할의 16회 클래스 무관 NMS 적용을 보고합니다. 보존 `final_table.py`는 과거 e/f, 즉 논문 c/d에만 후처리를 적용하고, `apply_g2.py`는 결합 모델의 두 분할을 처리합니다. 보존 CSV도 논문 a/b의 NMS 전체 결과를 포함하지 않습니다. 원본 묶음에서 전체 실행 자료를 확인하지 못했습니다.
2. 공개본의 평가 명령은 지정한 저장 예측에 NMS를 적용할 수 있지만, 이것만으로 원본의 누락 결과를 이미 복원했다고 주장하지 않습니다.
3. 최종 논문 그림 1·2의 이미지 파일은 보존돼 있지만 생성기는 조사 범위에서 확인되지 않았습니다. 이 저장소는 그림 생성 코드를 제공한다고 주장하지 않습니다.
4. 전체 환경 lockfile이 없습니다. 보존된 버전 기록과 이번 코드 검사 환경을 구분합니다.

## 논문 표와 보존 CSV

논문 표 1의 기준 (a) 완전일치율은 **83.0%**이며 보존 `results/table1_ablation.csv`의 대응하는 과거 c 행 pct는 **82.9**입니다. 논문 결과를 소개할 때는 논문 표기값을 사용합니다. 원본 CSV를 변경하거나 이번 정리에서 비율을 다시 계산해 대체하지 않았습니다.

보존 table1 CSV에는 논문 표 1의 mAP와 CI 열이 없고, 보존 table2 CSV에는 논문 a/b의 NMS 행이 없습니다. 보존 CSV와 최종 논문 표 전체가 동일하다고 설명하지 않습니다. [paper_tables.json](paper_tables.json)은 논문 표의 문자열을 그대로 추출한 별도 참고 자료입니다.

분할당 Test 75장의 소규모 데이터와 신뢰구간 중첩에 관한 논문의 한계는 그대로 유지합니다. 16회 저하가 없었다는 관찰을 통계적 우위나 일반화 보장으로 확대하지 않습니다.
