# 공개 코드 검사 결과

검사일: 2026-11-08.

- Python 3.12.7에서 Python 파일 10개의 구문 파싱을 통과했습니다.
- 원본 `final_table.py`의 연구 함수 12개와 공개본 함수의 AST가 모두 일치했습니다.
- 공통 학습 조건·증강 ON/OFF·고정 클래스 복제 배수를 원본과 대조했습니다.
- 학습·추론·평가·복제·분할 복원 CLI 5개의 `--help`는 `python -S` 환경에서도 통과했습니다. 설치된 site-packages를 로드하지 않는 검사입니다.
- 합성 입력을 이용한 단위 검사 10개를 통과했습니다.
- 기존 분할 JSON 5개와 28클래스 순서를 바꾸지 않았습니다.
- 데이터·가중치·학습 출력·임시 검사 파일의 Git 제외 규칙을 확인했습니다.
- 조사한 원본 파일 90개의 SHA-256은 공개본 준비 후에도 같았습니다.

실제 데이터로 학습·추론·완전일치 평가를 실행하지 않았습니다. 단위 검사에 사용한 숫자·폴리곤·파일은 코드 동작 확인용 가상 입력이며 연구 결과가 아닙니다. 논문 전체 수치 재현을 완료했다는 뜻이 아닙니다.
